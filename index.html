🎮 ROBLOX GAME MATCHES

Welcome to MAD AIRPORT Roblox Game Matches! All players must follow these rules.

01 — Match Verification

Every match must be checked before it begins.

02 — Checking Live Camera (CLC)

Matches must include Checking Live Camera (CLC).

03 — Fair Play Test

Every match must be tested for fairness before the game starts.

04 — Teams or Solo

Each player must have a teammate or play solo.

05 — Club Name and Picture

Every player must provide a club name. If no picture is uploaded, an AI-generated picture will be created.

06 — Roblox Game Requirement

All official matches must take place in the agreed Roblox game.
