🎮 ROBLOX GAME MATCHES

Welcome to MAD AIRPORT Roblox Game Matches! All participants must follow these match rules.

01 — Match Verification

Every match must be checked and verified before it begins.

02 — Checking Live Camera (CLC)

Matches must include Checking Live Camera (CLC), according to the match requirements.

03 — Fair Play Test

Every match must be tested and checked for fairness before the official game starts.

04 — Teams or Solo

Each player must have a teammate or register to play solo.

05 — Club Name and Picture

Every participant must provide a club name. If no club picture is uploaded, an AI-generated picture will be created for the club.

06 — Roblox Game Requirement

All official matches must take place in the agreed Roblox game.
